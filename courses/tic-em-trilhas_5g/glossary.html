Basic 5g - Glossary

Tip

Look here for a complete Telecommunications Glossary

3

3GPP (3rd Generation Partnership Project)

is a collaboration between several telecommunications‑standardization organizations, responsible for developing and maintaining standards for mobile technologies, including 2G, 3G, 4G and 5G.

5

5G

the fifth generation of mobile networks, delivering higher speed, capacity, and efficiency in wireless communication.

5GC (5G Core Network)

is the central component of the 5G network that manages user mobility, authentication, device connectivity, data routing, and other essential services.

5GS (5G System)

is the fifth‑generation mobile system, encompassing the entire 5G architecture and ecosystem components.

5QI (5G Quality of Service Identifier)

is a numeric indicator that represents Quality of Service (QoS) in 5G networks.

A

AMF (Access and Mobility Management Function)

Network Function in the 5G Core Network (5GC) architecture responsible for managing device registration and authentication, as well as handling user mobility.

API (Application Programming Interface)

a set of rules and protocols that enable communication and interaction between different software components.

AUSF (Authentication Server Function)

Network Function in the 5G Core Network (5GC) architecture that handles the authentication of devices wishing to connect to the 5G network.

AS (Standalone)

a standalone 5G architecture that does not require support from 4G networks.

C

CUPS (Control and User Plane Separation)

the concept of separating the control plane and user plane in a telecommunications network.

D

DSS (Dynamic Spectrum Sharing)

technology that allows 4G and 5G networks to share the same spectrum dynamically.

E

eMBB (Enhanced Mobile Broadband)

one of the three main 5G use cases, focused on delivering high‑speed mobile broadband connectivity.

eNodeB (Evolved NodeB)

a base station used in LTE networks.

EPC (Evolved Packet Core)

the central component of the 4G network that manages user mobility, authentication, device connectivity, data routing, and other essential services.

F

FDD (Frequency Division Duplex)

a duplexing technology that uses separate frequencies for data transmission and reception.

G

gNodeB (Next Generation NodeB): a base station used in 5G networks.
GTP‑U (GPRS Tunnelling Protocol – User Plane): a tunnelling protocol used to transport user data in mobile networks.

H

HTTP (Hypertext Transfer Protocol): the communication protocol used to transfer data on the Internet.

I

IETF (Internet Engineering Task Force): an organization of volunteers, experts, and professionals who develop and promote Internet standards.
IMS (IP Multimedia Subsystem): an architecture that enables multimedia services—such as voice calls, video, and messaging—over IP networks.
IMT (International Mobile Telecommunications): a family of standards for mobile systems, including 2G, 3G, 4G, and 5G.
IoT (Internet of Things): the network of physical devices connected to the Internet that can collect and exchange data.

L

LTE‑Advanced Pro (Long Term Evolution‑Advanced Pro): an evolution of LTE with more advanced features.
LTE (Long Term Evolution): a high‑speed mobile‑network technology that represents an evolution of 3G.

M

MIMO (Multiple‑Input Multiple‑Output): transmission and reception through multiple inputs and outputs. Antennas are optimized to increase data rates while improving efficiency with more directional beams, better power use, and longer device battery life.
mMTC (Massive Machine‑Type Communications): one of the three main 5G use cases, aimed at connecting large numbers of IoT devices with low power consumption and efficient resource use.
Modulation: an operation performed on the signal or data to be transmitted to produce a signal suitable for the chosen transmission medium. The modulation technique “shapes” the signal’s characteristics to match the channel.
MU‑MIMO (Multi‑User MIMO): a MIMO technique that allows simultaneous communication with multiple devices.

N

N2: interface between radio base stations and the Access and Mobility Management Function (AMF) in the 5G core.
N3: interface between radio base stations and the User Plane Function (UPF) in the 5G core.
N3IWF (Non‑3GPP Interworking Function): enables interconnection between 3GPP 5G networks and non‑3GPP networks.
NE (Network Element): generic term for individual devices or entities in a point‑to‑point architecture.
NF (Network Function): generic term for individual devices or entities in a service‑based architecture.
NFV (Network Function Virtualisation): an approach that virtualizes Network Functions, running them on virtual machines instead of dedicated hardware.
NG RAN (Next Generation Radio Access Network): the part of the 5G architecture that handles wireless access.
NR (New Radio): the portion of the 5G specification that defines the air interface and related technologies.
NRF (Network Function Repository Function): Network Function in the 5G Core Network that acts as a central repository of information on available Network Functions.
NSA (Non‑Standalone): a 5G architecture that relies on existing 4G infrastructure for some functionalities.

O

OFDMA (Orthogonal Frequency Division Multiple Access): multiple‑access technique that subdivides a frequency channel into smaller sub‑carriers, allowing small packets to be sent in parallel to multiple devices.
OPNFV (Open Platform for NFV): a collaborative open‑source project aimed at facilitating the development and testing of NFV solutions.

P

PCF (Policy Control Function): Network Function in the 5G Core Network responsible for service‑policy control and enforcement.
PDU (Packet Data Unit): the basic data unit used in communication networks to represent information in packets.

Q

QAM (Quadrature Amplitude Modulation): a modulation technique used to transmit data in communication networks.
QoS (Quality of Service): the ability of a telecommunications network to provide different levels of priority, performance, and traffic treatment for different service types.

R

RAN (Radio Access Network): the part of the network responsible for wireless communication between devices and the network infrastructure.
REST (Representational State Transfer): a software‑architecture style that uses HTTP to create web services accessible through URLs.

S

SBI (Service‑Based Interface): a communication interface used in 5G network architecture.
SC‑FDMA (Single Carrier Frequency Division Multiple Access): a multiple‑access technique used in the LTE uplink.
SIP (Session Initiation Protocol): a communication protocol used to initiate, modify, and terminate sessions in IP networks.
SMF (Session Management Function): Network Function in the 5G Core Network that manages establishment, modification, and termination of PDU sessions.
SON (Self‑Organizing Networks): a set of technologies and algorithms that enable self‑configuration, self‑management, and self‑optimization of the network.

T

TDD (Time Division Duplex): a duplexing technology that uses the same frequency channel at different time intervals to transmit and receive data.
TDMA (Time Division Multiple Access): multiple‑access technique that digitally processes voice signals, allocating information from different users to different time slots within the same frequency channel.

U

UDM (Unified Data Management): Network Function in the 5G Core Network that handles user‑data management.
UDR (Unified Data Repository): Network Function in the 5G Core Network that serves as a centralized database of user information.
UE (User Equipment): the end‑user device, such as smartphones, tablets, USB modems, and more.
UPF (User Plane Function): Network Function in the 5G Core Network that processes and forwards user‑data traffic.
URLLC (Ultra‑Reliable Low‑Latency Communications): one of the three main 5G use cases, intended to provide highly reliable communications with the lowest possible latency.
Uu: the air (radio) interface between the user device and the base station in 5G.
WCDMA (Wideband Code Division Multiple Access): multiple‑access technique that allocates information from different users in the same time slot and frequency channel, separating each user through distinct random codes.

V

VoNR (Voice over NR): technology that enables voice calls over the 5G network.
VoLTE (Voice over LTE): technology that enables voice calls over the 4G network.
VoIP (Voice over IP): technology that carries voice calls over the Internet or other IP networks.

X

X2/Xn: interfaces that connect radio base stations in 5G, enabling communication between them.

W

WLAN (Wireless Local Area Network): a wireless (Wi‑Fi) communication network that connects devices—such as computers, smartphones, and other compatible devices—within a limited geographic area.
