Classes (01)

Module 01 - Prof. Eduardo Moreno / Prof. Loreno Menezes da Silveira

  • CL01: Introduction to Private Networks (15-04)
  • CL02: Private Networks - Technology (17-04)
  • CL03: 5G Architecture (22-04)
  • CL04: Importance of segmentation in private networks (24-04)
  • CL05: Segmentation scenarios in private cellular networks and use cases. (25-04)
  • CL06: Configuration and design of VLAN's for different traffic classes (voice, video, data, IoT). (29-04)
  • CL07: Considerations for the use of VLAN's in private cellular networks. (06-05)
  • CL08: Frequency spectrum and licensed and unlicensed bands. (08-05)
  • CL09: Allocation of frequencies for private networks in Brazil. Processes for obtaining licenses and regulations (SLP and UTE). (09-05)

Module 02 - Prof. Almir Meira Alves

  • CL01: Applying Troubleshooting Tools in Networks: Essential tools: ping, tcpdump, Wireshark, nmap, netcat, socat, logcat. (13-05)
  • CL02: Implementing Cybersecurity in Mobile Networks: Vulnerabilities in applications for Industry 4.0. Basic principles of security in private cellular networks. Firewall configuration and policies for network isolation. (15-05)
  • CL03: Segmentation and access control in private networks. Interpreting the Signaling Flow in Mobile Networks (16-05)
  • CL04: Signaling protocols: GTP, RRC, NGAP, NAS. Message analysis: NGsetup Request/Response, F1Setup Request/Response, RRC Signaling. Network procedures: UE Attach, PDU Session Establishment, authentication, mobility (handover).
  • CL05: Interpreting Core Parameters: Core architecture for 4G and 5G networks. Main network functions (NFs) in 4G (MME, HSS, SPGWC, PCRF) and 5G (NRF, NSSF, AMF, AUSF, UDM, UDR, SMF, PCF).
  • CL06: Interpreting RAN Parameters: Configuring parameters appropriate to the needs of the network/client.
  • CL07: Main RAN parameters: bands, MCS, modulation, rank.
  • CL08: Applying Advanced Technologies for Network Virtualization: Technologies: SR-IOV, DPDK, eBPF, Multus/Calico.
  • CL09: Discussing Open RAN: Fundamentals and network disaggregation: RU, DU and CU. Functional splits, O-RAN Alliance architecture and open interfaces.

Module 03 - Prof. Vinícius da Silva Borges

  • CL01: Dimensioning Infrastructure and Backhaul: Identifying coverage and capacity parameters.
  • CL02: Infrastructure and backhaul planning.
  • CL03: Planning tools: Celplanner.
  • CL04: Discussing Use Cases for Private Networks (part I)
  • CL05: Discussing Use Cases for Private Networks (part II)
  • CL06: Applications for Industry 4.0: needs, challenges and implementation requirements.
  • CL07: Applying Open Solutions for RAN and Core Emulation. Lab tools: OAI, srsRAN, UERANSIM, C2N.
  • CL08: Management protocols: SNMP.
  • CL09: Management tools such as Zabbix and applications in private networks.

Module 04 - Prof. Vinícius da Silva Borges

  • CL01: Interpreting TSN Architectures
  • CL02: TSN protocols and integration with technologies such as Wi-Fi and 5G. (part I)
  • CL03: TSN protocols and integration with technologies such as Wi-Fi and 5G. (part II)
  • CL04: Interpreting Industrial Network Protocols
  • CL05: Main protocols: Modbus RTU, Modbus TCP, CAN, Ethernet/IP, EtherCAT (part I)
  • CL06: Main protocols: Modbus RTU, Modbus TCP, CAN, Ethernet/IP, EtherCAT (part II)
  • CL07: Main protocols: Modbus RTU, Modbus TCP, CAN, Ethernet/IP, EtherCAT (part III)
  • CL08: TSN concepts applied to industrial networks (part I)
  • CL09: TSN concepts applied to industrial networks (part II)
