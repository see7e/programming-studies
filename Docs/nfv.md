# Network Function Virtualization (NFV)

> [!NOTE]
> is the replacement of network appliance hardware with virtual machines. The virtual machines use a hypervisor to run networking software and processes such as routing and load balancing.
> https://www.vmware.com/topics/network-functions-virtualization-nfv
