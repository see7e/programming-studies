# 📖 Telecommunications Glossary

> [!TIP]
> #### How to read this glossary
> - **Bold acronym**: The term itself
> - *Meaning*: Unabbreviated phrase or formal name
> - *Short Definition*: One‑line explainer focused on the context of 4G/5G private networks
> 
> *A concise, alphabetically‑organised reference for key terms in private mobile networks.*
> 🔹 = **entry added to enrich your original list**

## 0–9

|Acronym|Meaning|Short Definition|
|---|---|---|
|**3GPP**|3rd Generation Partnership Project|Global partnership that develops and maintains mobile standards (2G → 5G).|

## 5

| Acronym | Meaning                         | Short Definition                                                                                        |
| ------- | ------------------------------- | ------------------------------------------------------------------------------------------------------- |
| **5G**  | Fifth‑Generation Mobile Network | Latest cellular generation, delivering higher data‑rates, massive device density and ultra‑low latency. |
| **5GC** | 5G Core Network                 | Central 5G component in charge of mobility, authentication, session management and data routing.        |
| **5GS** | 5G System                       | The complete 5G ecosystem (radio, transport and core) as specified by 3GPP.                             |
| **5QI** | 5G QoS Identifier               | Numerical tag that maps a flow to a predefined 5G Quality‑of‑Service profile.                           |

## A

|Acronym|Meaning|Short Definition|
|---|---|---|
|**AMF**|Access & Mobility Management Function|5GC network function for device registration, authentication and mobility handling.|
|**API**|Application Programming Interface|Set of rules that let independent software components talk to each other.|
|**AS**|Stand‑Alone (Architecture)|Pure‑5G deployment that does **not** rely on legacy 4G infrastructure.|
|**AUSF**|Authentication Server Function|5GC function that performs user‑equipment authentication.|
|🔹 **AI/ML**|Artificial Intelligence / Machine Learning|Data‑driven techniques increasingly used for network optimisation and automation.|

## B 🔹

|Acronym|Meaning|Short Definition|
|---|---|---|
|**BBU**|Baseband Unit|Processing element of a (g)NodeB that handles baseband radio functions.|
|**BSS**|Business Support Systems|Operational support tools for billing, customer‑care and service fulfilment.|

## C

|Acronym|Meaning|Short Definition|
|---|---|---|
|**CUPS**|Control & User‑Plane Separation|Architectural split of signalling and data forwarding planes for flexible deployment.|

## D

|Acronym|Meaning|Short Definition|
|---|---|---|
|**DSS**|Dynamic Spectrum Sharing|Technique allowing 4G & 5G to coexist dynamically on the **same** frequency block.|

## E

|Acronym|Meaning|Short Definition|
|---|---|---|
|**eMBB**|Enhanced Mobile Broadband|5G use‑case focusing on multi‑gigabit, consumer‑grade broadband.|
|**eNodeB**|Evolved Node B|LTE (4G) radio base‑station.|
|**EPC**|Evolved Packet Core|4G core network handling mobility, authentication and packet routing.|

## F

|Acronym|Meaning|Short Definition|
|---|---|---|
|**FDD**|Frequency Division Duplex|Uses two separate frequency bands for uplink and downlink.|

## G

|Acronym|Meaning|Short Definition|
|---|---|---|
|**gNodeB**|(Next‑Generation) Node B|5G radio base‑station.|
|**GTP‑U**|GPRS Tunnelling Protocol – User Plane|User‑traffic tunnelling protocol in 3G/4G/5G cores.|

## H

|Acronym|Meaning|Short Definition|
|---|---|---|
|**HTTP**|Hypertext Transfer Protocol|Core protocol for web data exchange.|

## I

|Acronym|Meaning|Short Definition|
|---|---|---|
|**IETF**|Internet Engineering Task Force|Open community producing Internet standards (RFCs).|
|**IMS**|IP Multimedia Subsystem|Architectural framework for delivering voice/video/messaging over IP.|
|**IMT**|International Mobile Telecommunications|ITU family of standards for mobile systems (IMT‑2000, IMT‑Advanced, IMT‑2020).|
|**IoT**|Internet of Things|Network of physical objects that collect and exchange data.|

## J 🔹

|Acronym|Meaning|Short Definition|
|---|---|---|
|**JSON**|JavaScript Object Notation|Lightweight data‑interchange format widely used in APIs.|
|**Jitter**|—|Variation in packet delay; critical metric for real‑time traffic.|

## K 🔹

|Acronym|Meaning|Short Definition|
|---|---|---|
|**KPI**|Key Performance Indicator|Quantifiable measure to evaluate network quality and business success.|

## L

|Acronym|Meaning|Short Definition|
|---|---|---|
|**LTE**|Long‑Term Evolution|4G radio technology offering high‑speed mobile broadband.|
|**LTE‑Advanced Pro**|—|Enhanced LTE release with features such as 256‑QAM, 4×4 MIMO, LAA, NB‑IoT.|

## M

|Acronym|Meaning|Short Definition|
|---|---|---|
|**MIMO**|Multiple‑Input Multiple‑Output|Uses multiple antennas to boost throughput and reliability.|
|**mMTC**|Massive Machine‑Type Communications|5G use‑case for huge numbers of low‑power IoT devices.|
|**Modulation**|—|Signal‑processing technique that adapts data to a transmission medium.|
|**MU‑MIMO**|Multi‑User MIMO|Variant of MIMO enabling simultaneous streams to multiple users.|

## N

|Acronym|Meaning|Short Definition|
|---|---|---|
|**N2**|—|Interface between (g)NodeB and AMF in 5G.|
|**N3**|—|Interface between (g)NodeB and UPF in 5G.|
|**N3IWF**|Non‑3GPP Interworking Function|Gateway allowing Wi‑Fi or fixed access into the 5G Core.|
|**NE**|Network Element|Generic term for a physical telecom device.|
|**NF**|Network Function|Logical building‑block in service‑based architecture.|
|**NFV**|Network Function Virtualisation|Running network functions as virtualised software.|
|**NG‑RAN**|Next‑Generation RAN|3GPP umbrella term for 5G radio access network.|
|**NR**|New Radio|5G radio interface specification.|
|**NRF**|Network Function Repository Function|5GC registry holding NF profiles and discovery data.|
|**NSA**|Non‑Standalone|5G deployment that leverages an existing 4G core for control.|

## O

|Acronym|Meaning|Short Definition|
|---|---|---|
|**OFDMA**|Orthogonal Frequency‑Division Multiple Access|Multiplexing scheme slicing spectrum into many orthogonal sub‑carriers.|
|**OPNFV**|Open Platform for NFV|Open‑source project for building and testing NFV solutions.|

## P

|Acronym|Meaning|Short Definition|
|---|---|---|
|**PCF**|Policy Control Function|5GC function that enforces service and charging policies.|
|**PDU**|Packet Data Unit|Basic data‑transport block in networking.|

## Q

|Acronym|Meaning|Short Definition|
|---|---|---|
|**QAM**|Quadrature Amplitude Modulation|Modulation scheme combining amplitude and phase variations.|
|**QoS**|Quality of Service|Ability to provide traffic differentiation in a network.|

## R

|Acronym|Meaning|Short Definition|
|---|---|---|
|**RAN**|Radio Access Network|Portion of the network linking user devices to the core.|
|**REST**|Representational State Transfer|Web‑service style that uses standard HTTP verbs and URIs.|

## S

|Acronym|Meaning|Short Definition|
|---|---|---|
|**SBI**|Service‑Based Interface|HTTP/JSON interface pattern used by 5GC network functions.|
|**SC‑FDMA**|Single‑Carrier FDMA|Uplink multiple‑access scheme used in LTE.|
|**SIP**|Session Initiation Protocol|Signalling protocol for establishing multimedia sessions.|
|**SMF**|Session Management Function|5GC function managing PDU sessions and IP address allocation.|
|**SON**|Self‑Organising Network|Algorithms that automate configuration, optimisation and healing.|

## T

|Acronym|Meaning|Short Definition|
|---|---|---|
|**TDD**|Time Division Duplex|Shares a single frequency by alternating transmit/receive timeslots.|
|**TDMA**|Time‑Division Multiple Access|Allocates distinct time slots to multiple users on the same carrier.|

## U

|Acronym|Meaning|Short Definition|
|---|---|---|
|**UDM**|Unified Data Management|5GC function for subscriber data storage and handling.|
|**UDR**|Unified Data Repository|Central database holding structured subscriber & network data.|
|**UE**|User Equipment|End‑user device (phone, router, IoT modem…).|
|**UPF**|User Plane Function|5GC data‑plane anchor that forwards user traffic.|
|**URLLC**|Ultra‑Reliable Low‑Latency Communications|5G use‑case demanding <1 ms latency & >99.999% reliability.|
|**Uu**|Air Interface|Radio link between UE and (g)NodeB.|
|**WCDMA**|Wideband CDMA|3G multiple‑access technique using spreading codes.|

## V

|Acronym|Meaning|Short Definition|
|---|---|---|
|**VoIP**|Voice over IP|Routing voice calls over packet‑switched IP networks.|
|**VoLTE**|Voice over LTE|Voice service delivered over the 4G EPC & IMS.|
|**VoNR**|Voice over NR|Native 5G voice service running on 5GC & IMS.|

## W

|Acronym|Meaning|Short Definition|
|---|---|---|
|**WLAN**|Wireless Local Area Network|Short‑range wireless network (e.g. Wi‑Fi).|

## X

|Acronym|Meaning|Short Definition|
|---|---|---|
|**X2/Xn**|—|Interfaces inter‑connecting (e)NodeBs or gNodeBs for coordination and mobility.|

## Y 🔹

|Acronym|Meaning|Short Definition|
|---|---|---|
|**YANG**|Yet Another Next‑Generation|Data‑modelling language used in network configuration protocols (NETCONF/RESTCONF).|

## Z 🔹

|Acronym|Meaning|Short Definition|
|---|---|---|
|**ZUC**|Zu Chongzhi Stream Cipher|3GPP confidentiality & integrity algorithm used in LTE & 5G.|
